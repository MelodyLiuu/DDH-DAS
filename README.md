# 兒童髖關節偵測輔助系統 DDH-DAS 
> 本作品參加「2024 年全國大專校院智慧創新暨跨域整合創作競賽」— 數位永續科技組 佳作

##  專案概述

發展性髖關節發育不良是嬰幼兒中常見的髖關節發育異常疾病，台灣每 2000 名新生兒中約有 3 人罹患此病。現行診斷流程須由醫師手動判讀超音波影像並計算 Alpha 角與 Beta 角，不僅耗時，且影像可能因氣體或骨骼干擾而降低清晰度，增加判讀困難。

**DDH-DAS** 是一套專為兒科醫師設計的影像輔助診斷系統，整合影像增強、深度學習標記與自動角度計算，提供完整的髖關節影像輔助判讀流程：

-  **影像增強**：自適應直方圖均衡化（AHE），改善超音波影像對比度
-  **自動標記**：U-Net + KeypointNet 自動識別特徵點並連線
-  **角度計算**：I-AD 演算法自動計算 Alpha 角與 Beta 角
-  **資料保存**：依病歷號儲存影像與診斷結果，支援 Excel 匯出

---

##  主要功能

### A. 影像增強

使用者將髖關節超音波影像輸入系統後，可選擇是否啟用 AHE 影像增強。增強後若效果不滿意，可一鍵還原至原始影像後重新處理，確保後續模型辨識的準確性。

### B. 標記結果

增強後的影像經 U-Net 模型進行語意分割，再透過 KeypointNet 標記股骨頭、髖關節、髖臼窩等關鍵特徵點並自動連線。接著由 I-AD 演算法計算出 Alpha 角與 Beta 角，並將標記結果、角度數值及模型準確度一併顯示於介面。

### C. 結果描述

根據 Alpha 角與 Beta 角的數值，系統自動對影像進行分類，並依骨盆與髖關節的包覆關係生成對應的狀況描述，方便醫師快速判讀病況。醫師亦可在 Comment 欄位補充醫囑與臨床說明。

### D. 資料保存

確認診斷結果後，系統提供三種操作選項：依病歷號儲存至資料庫、匯出標記後影像，或匯出 Excel 資料表。醫師可隨時查詢與修改歷史病歷。

##  使用工具

### 演算法與模型

| 技術 | 用途 |
|------|------|
| **AHE（自適應直方圖均衡化）** | 重新分佈影像亮度值，改善局部對比度，增強超音波影像細節 |
| **U-Net** | 醫學影像語意分割主幹網路，對每個像素進行分類 |
| **KeypointNet** | 與 U-Net 端對端整合，標記股骨頭、髖臼窩等關鍵特徵點並連線 |
| **I-AD（Image-Angle Detection）** | 自行設計的角度測量演算法，透過斜率計算與三角函數求得 Alpha / Beta 角 |

### 訓練資料

| 項目 | 說明 |
|------|------|
| 資料來源 | 與區域醫院合作提供 |

| 資料分類 | 左側 / 右側分別預處理後訓練 |
